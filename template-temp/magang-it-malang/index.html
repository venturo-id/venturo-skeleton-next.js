Magang IT / Internship Programmer Malang

Kesempatan magang menjadi programmer profesional di Malang, Jawa Timur untuk SMK atau universitas. Minimal 3 bulan, jika lolos seleksi berkesempatan diterima kerja di perusahaan kami.
